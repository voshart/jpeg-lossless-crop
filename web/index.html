What “lossless” means here

The JPEG engine copies retained transform coefficients rather than decoding and re-encoding pixels. The file itself changes, and the displayed selection may expand to block boundaries. This is not a secure-redaction tool: boundary blocks can retain information outside the visible edge.

Processing stays in this browser. The app has no image-upload endpoint, analytics, external fonts, or saved image history. Keeping original metadata can also keep GPS coordinates and an uncropped thumbnail.
